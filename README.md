# harness

My personal software harness: the goals, process, skills and templates Claude works by. Source of truth, symlinked into `~/.claude`.

- `CLAUDE.md` → `~/.claude/CLAUDE.md` (global goals and practice, loaded in every project; "the standards" in the skills)
- `skills/*` → `~/.claude/skills/*` (the process in `CLAUDE.md` says when each runs)
- `templates/`: copy `requirements.md` and `architecture.md` into a project's `docs/`, `feature.md` to `docs/features/<area>.md`, and `claude-settings.json` to `.claude/settings.json`

Rules: AI proposes changes here, I approve. Prefer deleting to adding. If I can't explain a piece in one sentence, cut it.

The [AI Process Log](https://app.notion.com/p/AI-Process-Log-3f8c4dbb621780b19978f2741c76422c) collects proposed changes and holds the periodic review steps.
